# MatrixL, лаунчер Minecraft (Windows .exe)

Лаунчер MatrixL: моды, плагины, сборки и запуск игры в одном приложении на Electron.

## Что умеет
- **Без регистрации в лаунчере.** Достаточно войти в игровой аккаунт:
  - **Ely.by**, в игре и на серверах Ely.by будет ваш скин (подключается `authlib-injector`, скачивается автоматически при первом запуске);
  - **Microsoft**, лицензионный аккаунт (вход через страницу Microsoft, как в других лаунчерах);
  - **обычный**, «оффлайн», по нику.
  Рядом с ником показывается голова вашего скина, а шестерёнка рядом открывает окно «Скин и плащ»: у аккаунта Microsoft скин и плащ меняются прямо в лаунчере, у Ely.by они меняются на сайте.
  Пароль Ely.by лаунчер не хранит, токены лежат в зашифрованном виде (DPAPI/Keychain).
- **Главная страница = лаунчер**: фон из скриншотов игры, «Играть» справа снизу, «Настройки экземпляра» слева.
- **Скачивание версий Minecraft**: релизы и снапшоты, нужная Java, автоматически. Загрузчик (Vanilla / Fabric / Quilt / Forge / NeoForge) выбирается в окне создания и позже в «Настройках экземпляра»; показываются только те, что существуют для выбранной версии (для 1.12.2, только Forge). Для каждого загрузчика предлагается **рекомендуемая версия** (у Forge, из официальных promotions, у Fabric/Quilt, последняя стабильная), можно выбрать и другую.
- **Установка модов в выбранную версию**: карточка мода в разделе «Моды» → «Установить в Minecraft» → выбрать установку. Версия мода подбирается под игру и загрузчик, обязательные зависимости ставятся сами.
- **Экземпляры значками.** На главной все экземпляры, плитки с аватарками; аватарку можно загрузить из файла (PNG/JPG/WEBP/GIF до 3 МБ) или выбрать готовую. В настройках экземпляра также: показ скриншотов на фоне и скорость их смены, полноэкранный режим, размер окна, свои параметры JVM.
- **CurseForge.** В «Модах» (в приложении) моды Modrinth и CurseForge показываются в одном списке: у Modrinth зелёная плашка, у CurseForge оранжевая, одинаковые проекты склеиваются в одну карточку; можно оставить только один источник. В «Сборках» источник переключается Modrinth / CurseForge. API-ключ CurseForge вшивается в приложение при сборке (`src/curseforge-key.js`, в репозиторий не попадает), пользователю вводить его не нужно. Моды ставятся в экземпляр с обязательными зависимостями; сборки CurseForge (.zip с manifest.json) ставятся как экземпляр. Если автор мода запретил скачивание сторонними программами, такой файл пропускается и показывается в списке, его нужно скачать вручную.
- **Игра всегда запускается в полноэкранном режиме.**
- **Темы оформления.** Янтарная по умолчанию, зелёная, чёрно-белая и другие, в настройках.
- **OptiFine.** Ставится вместе с Forge, в том числе прямо при создании экземпляра.
- **Отмена скачивания.** Любую установку (версия игры, сборка, моды) можно отменить кнопкой «Отмена» в плашке «Загрузки».
- **Выбор способа скачивания.** В списке версий мода или сборки кнопка «Скачать» предлагает скачать файл как обычно или установить в экземпляр.
- **Сборки .mrpack.** В карточке сборки (раздел «Сборки») выберите версию и нажмите «Установить как экземпляр», либо откройте скачанный файл кнопкой «Установить из файла .mrpack…». Лаунчер создаёт экземпляр с нужной версией Minecraft и загрузчиком, скачивает все файлы с проверкой контрольных сумм (только с modrinth.com, GitHub и GitLab) и копирует overrides. При ошибке экземпляр удаляется.
- **Избранное.** Кнопка «Установить всё в Minecraft» ставит все моды из избранного (или из выбранной коллекции) в выбранный экземпляр с зависимостями; ошибка одного мода не мешает остальным. Свои коллекции создаются прямо на странице избранного, карточки добавляются кнопкой «В коллекцию».
- **Фон главной.** Показываются только скриншоты выбранного экземпляра; вместо них можно поставить свою картинку или отключить фон.
- **Память по характеристикам компьютера.** В настройках экземпляра видны процессор, объём и свободная ОЗУ. Режим «подбирать автоматически» выбирает объём при каждом запуске по загрузчику, числу модов и возможностям ПК (не больше 75% памяти, системе остаётся минимум 2 ГБ). Ручной выбор ограничен тем, что реально есть в компьютере, с предупреждением, если свободной памяти сейчас не хватает.
- **Изменения файлов видны сразу, без перезапуска**: добавили или удалили мод в папке `mods`, список и счётчик модов обновятся; сделали скриншот в игре (F2), он появится на фоне.


| Файл | Что это |
|---|---|
| `MatrixL-Setup-<версия>.exe` | Установщик: выбор папки, ярлыки на рабочем столе и в меню «Пуск», удаление через «Приложения» |
| `MatrixL-portable.exe` | Портативная версия: запускается без установки, можно держать на флешке |

Требования: Windows 10 или 11 (64 бит) и интернет при первом запуске: лаунчер сам скачивает нужную Java, версии Minecraft и загрузчики.
Windows SmartScreen может предупредить о неизвестном издателе, потому что файл не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Исходный код
Лаунчер написан на Electron (Node.js) без фреймворков. Лицензия GPL-3.0: копии и изменённые версии нужно распространять под той же лицензией с открытым исходным кодом.

    src/                    главный процесс Electron
      main.js               окно, IPC, статус Discord, запуск игры
      core.js               версии Minecraft, загрузчики, Java, моды, сборки, OptiFine
      accounts.js           аккаунты: Microsoft, Ely.by, обычный; скины и плащи
      discord.js            Rich Presence
      ms-app.example.js     шаблон ID приложения Microsoft
      discord-app.example.js      шаблон ID приложения Discord
      discord-logo.js       необязательная ссылка на картинку для статуса Discord
      curseforge-key.example.js   шаблон ключа CurseForge
      preload.js            безопасный мост между окном и ядром
    site/                   интерфейс (HTML, CSS, JS), каталог модов и лаунчер
    build/                  иконки и картинки установщика, настройки NSIS
    discord-assets/logo.png картинка для Art Assets в Discord
    .github/workflows/      сборка .exe и публикация релиза
